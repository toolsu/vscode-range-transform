运行 **Range & Transform: Insert Sequence from Range**，然后输入一个范围：

```text
start:stop:step
```

- **`start`** 必填，决定序列的*类型*（见下表）。
- **`stop`** 可选。省略时序列会一直数下去：`1:` 填满所有光标，`mon::2` 隔一天取一个星期几。
- **`step`** 可选，默认为 `1`。它的正负号会自动修正，所以 `10:1` 不写 `-1` 也会倒数。

有多个光标时，每个光标得到一项，序列到最后一个光标为止。只有一个光标时没有地方分散，整个序列会用换行连接后插入：放一个光标，输入 `1:10`，就得到十行。

<Aside type="tip">
想在安装前先试试范围？[序列生成器](https://toolsu.com/convnum/zh-cn/tools/sequence-generator/)在浏览器里运行的是同样的 convnum 转换。
</Aside>

## `start` 可以是什么

[convnum](https://toolsu.com/convnum/zh-cn/) 能识别的任何内容：26 种数字体系加上日期，每一种都按自己的规则计数并写回。

| 类型 | 示例 | 结果 |
| --- | --- | --- |
| 十进制 | `1:10:2` | `1` `3` `5` `7` `9` |
| 补零的十进制 | `01:05` | `01` `02` `03` `04` `05` |
| 拉丁字母 | `a:e` 或 `A:E` | `a` `b` `c` `d` `e` 或 `A` `B` `C` `D` `E` |
| 罗马数字 | `II:X` | `II` `III` `IV` `V` … |
| 十六进制、二进制、八进制 | `0x1:0xf`、`0b1:0b101`、`0o1:0o7` | 保留前缀和大小写 |
| 东阿拉伯数字 | `٠:٥` | `٠` `١` `٢` `٣` `٤` `٥` |
| 英语数字词 | `one:five` | `one` `two` `three` `four` `five` |
| 英语序数词 | `first:fifth` | `first` `second` `third` … |
| 英语序数词缩写 | `1st:5th` | `1st` `2nd` `3rd` `4th` `5th` |
| 法语数字词 | `un:cinq` | `un` `deux` `trois` … |
| 法语序数词 | `premier:cinquième` | `premier` `deuxième` … |
| 法语序数词缩写 | `1er:5e` | `1er` `2e` `3e` `4e` `5e` |
| 中文数字 | `一:五` | `一` `二` `三` `四` `五` |
| 中文大写数字 | `壹:伍` | `壹` `贰` `叁` `肆` `伍` |
| 天干 | `甲:癸` | `甲` `乙` `丙` … |
| 地支 | `子:辰` | `子` `丑` `寅` `卯` `辰` |
| 二十四节气 | `立春:惊蛰` 或 `立春:驚蟄` | `立春` `雨水` `惊蛰` 或 `立春` `雨水` `驚蟄` |
| 希腊字母 | `α:ε` 或 `Α:Δ` | `α` `β` `γ` `δ` `ε` 或 `Α` `Β` `Γ` `Δ` |
| 希腊字母名称 | `Alpha:Delta` | `Alpha` `Beta` `Gamma` `Delta` |
| 西里尔字母 | `а:г` 或 `А:Г` | `а` `б` `в` `г` 或 `А` `Б` `В` `Г` |
| 希伯来字母 | `א:ה` | `א` `ב` `ג` `ד` `ה` |
| 北约音标 | `Alfa:Echo` | `Alfa` `Bravo` `Charlie` … |
| 星座 | `Aries:Cancer` | `Aries` `Taurus` `Gemini` `Cancer` |
| 月份名称 | `Jan:Jun`、`January:June`、`janvier:juin`、`1月:6月` | 缩写或完整形式，保留大小写和语言 |
| 星期名称 | `Mon:Fri`、`monday:friday`、`lundi:vendredi`、`星期一:星期五` | 缩写或完整形式，保留大小写和语言 |
| 日期 | `2023-01-01:2023-01-05` | 也支持 `.` `/` `,` 分隔符以及 `D-M-Y`、`M-D-Y` |
| 年月 | `2023-01:2023-06` | 按月递增 |
| 带月份名称的日期 | `Dec 25, 2023:Dec 29, 2023`、`Dec 25 2023:Dec 29 2023`、`25 Dec 2023:29 Dec 2023` | 保留 `start` 的格式 |
| 东亚日期 | `2023年12月25日:2023年12月29日`、`2023年12月:2024年3月`、`2023년 12월 25일:2023년 12월 29일` | 每个字段都有标记，不需要猜测 |

## 值得了解的细节

- **保留 `start` 的写法。** `MON:FRI` 保持大写，`0XA:0XF` 保留大写前缀，`01:10` 保留前导零，`一:十` 保持简体。
- **循环类型会绕回。** `fri::2` 会越过星期日进入下一周，`甲::3` 会在十天干中循环。
- **`step` 可以用任何进制写法。** `0x0A::0x10` 每次加十六，和 `0x0A::16` 一样。
- **`start` 和 `stop` 必须是同一类型。** `Mon:5` 什么也不会生成，按 <kbd>Enter</kbd> 之前输入框就会提示。注意那些意外属于同一类型的组合：`1` 和 `a` 都是十六进制数字，所以 `1:a` 会数出 `1` `2` … `9` `a`，而不是报错。
- **罗马数字与字母。** `I`、`V`、`X`、`C` 等也都是合法的拉丁字母，单个字母会被当作字母。要得到罗马数字，至少让一端有两个或更多字符（`II:X` 或 `I:XX`）。
- **月份和星期名称支持大约四十种语言。** `janvier:juin`、`Januar:Juni`、`enero:junio`、`январь:июнь`、`ocak:haziran`、`1月:6月` 和 `星期一:星期五` 都会用各自的语言计数并写回，并保留你输入的大小写以及缩写或完整形式。多种语言共用的名称会尽量根据范围的另一端判断：`mars:juin` 是法语，`mars:maj` 是瑞典语。没有线索时，使用更广泛的语言优先。
- **中文数字只识别规范写法。** `一万` 按普通中文数字计数，`壹万` 按大写数字计数。单独的 `万` 两者都不是（没有中文数字这样写），所以不会被识别，用 `一十` 代替 `十` 也不会被识别。

## 与范围相关的设置

`rangeTransform.defaultSequenceLength`（默认 `10`）决定范围没有 `stop` 时单个光标生成多少项。`rangeTransform.rememberLastInput` 会在输入框中预先填入上次使用的范围。
